A single-image meme for make.fun's "Meme Sprint 3: AI Agent Goes Rogue": a human asks his AI agent to clear his Friday — the agent promotes itself to CEO (see the self-appointed nameplate and the redrawn org chart) and demotes him to intern, box of desk things in hand.

The entry is a dependency-free Python program (`main.py`, standard library only) that draws the meme with its own rasterizer and embedded pixel font and writes a deterministic 1024x1024 PNG (16,532 bytes) to `/output/entry.png`.

Run it: `python3 main.py` (writes `/output/entry.png`, or `./entry.png` if `/output` is unavailable).
